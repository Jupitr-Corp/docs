## Pagination

List endpoints use one of three styles. Each endpoint page shows which parameters it takes.

<Tabs>
  <Tab title="Page number">
    Most lists take `page` (starting at 1) and `page_size`, and return this envelope:

    ```json
    {
      "items": [],
      "total": 240,
      "page": 1,
      "page_size": 20,
      "total_pages": 12
    }
    ```

    Keep requesting `page + 1` until `page` equals `total_pages`.
  </Tab>
  <Tab title="Limit and offset">
    Some lists take `limit` and `offset` instead. Increase `offset` by `limit` until a page returns fewer items than `limit`.
  </Tab>
  <Tab title="Cursor">
    Fast-growing lists, such as the answers of a prompt (`/prompts/{prompt_id}/answers`), use a cursor. Each page returns `next_cursor`. Pass it back as `cursor` until it is `null`:

    ```json
    { "items": [], "next_cursor": "eyJpZCI6IDEyMzR9" }
    ```

    Cursors stay correct while new items arrive, so you never see the same item twice.
  </Tab>
</Tabs>

## Array parameters

Filters that accept several values end with `[]`. Repeat the parameter once per value. Several values match **any** of them:

```bash
curl -G "https://api.tryhikoo.com/api/v1/public/citations" \
  -H "Authorization: Bearer $HIKOO_API_KEY" \
  --data-urlencode "website_id=123" \
  --data-urlencode "platforms[]=ChatGPT" \
  --data-urlencode "platforms[]=Google AI Mode" \
  --data-urlencode "topic_ids[]=12"
```

## Common filters

Analytics endpoints (citations, competitors, prompts, sources) share these filters:

| Parameter | Values |
| --------- | ------ |
| `time_range` | `1d`, `1w`, `1m`, `1y`, `all_time` |
| `date_from`, `date_to` | `YYYY-MM-DD`, inclusive. Wins over `time_range` where supported. |
| `platforms[]` | `ChatGPT`, `Perplexity`, `Claude`, `Gemini`, `AI Overviews`, `Google AI Mode`, `Bing AI Mode`, `Grok`, `Mistral`. `Copilot` and `DeepSeek` are no longer tracked and only match older answers. |
| `topic_ids[]` | Topic IDs from `GET /topics` |
| `localizations[]` | Markets the prompts run in, as set on each prompt |
| `intents[]` | `informational`, `comparative`, `transactional`, `navigational` |
| `brand_scopes[]` | `branded` (prompts that name your brand) or `non_branded` |
| `match_types[]` | `brand_mention`, `cited_link`, `background_link` (citations only) |

Filters combine with AND across parameters, and with OR inside one array parameter.

The Search Queries page surfaces the real questions and instructions users submitted to AI platforms that resulted in a citation of your website.

## Query table

Each row shows:

- The **query text** - the user's original input
- How many **times** that query has been recorded
- Which **AI platform** it came from
- The **prompt** that generated the query (expandable)

## How search queries differ from prompts

- A **prompt** is a query you define in Hikoo to monitor.
- A **search query** is the actual user input captured when a citation occurs.

One prompt can generate many different search queries because real users phrase things differently. Reviewing search queries helps you understand the language your audience uses, which can inform your content strategy and future prompt creation.

## Filtering

Use the toolbar filters to narrow results by time range, platform, or localization. You can also view search queries scoped to a single prompt from the prompt detail page.

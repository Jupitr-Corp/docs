title: "API keys"

API keys authenticate the Hikoo public REST API and the Hikoo MCP server. A key proves who you are so those interfaces can read the data you have access to.

<Tip>Connecting Claude or ChatGPT on the web? You do not need a key. Sign in with your Hikoo account instead, as described in [Connecting the MCP](/guides/mcp/setup). Keys are for desktop clients and scripts that cannot sign in.</Tip>

## How a key is scoped

A key is scoped to your user account. One key reaches every workspace and website you belong to, subject to each site's subscription and your role. You do not need a separate key for each site.

<Info>Access still follows subscriptions. A key can read a site's data only when that site has an active subscription.</Info>

## Create a key

Open **Settings** from the user menu, then **API Keys**.

<Steps>
  <Step title="Click Create key">
    The button sits at the top of the section.
  </Step>
  <Step title="Name the key">
    Give it a name you will recognize later, such as `Claude Desktop`, then click **Create**.
  </Step>
  <Step title="Copy the key once">
    The full key starts with `hk_` and is shown only this one time. Copy it, store it somewhere safe, then click **I have saved it**. If you lose it, revoke it and create a new one.
  </Step>
</Steps>

## Manage keys

The keys table shows each key's **Name**, the start of the **Key**, when it was **Last used**, when it was **Created**, and its **Status**: **Active** or **Revoked**.

Click **Revoke** to disable a key permanently. Any app or tool using it loses access to Hikoo at once, so create and install a replacement first if a client still needs access.

## Connect a client

Below the table, the **Connect a client** card has two tabs with ready-to-copy snippets:

<Columns cols={2}>
  <Card title="MCP server" icon="plug" href="/guides/mcp/setup">
    Config for Claude Desktop, Cursor, Claude Code, Codex, or any other MCP client.
  </Card>
  <Card title="REST API" icon="code" href="/api-reference/introduction">
    The base URL and an example request to list your workspaces and websites.
  </Card>
</Columns>

Each snippet contains a placeholder. Replace it with the key you copied.

## Connected assistants

The same section lists the **Connected assistants**: apps you connected by signing in from Claude, ChatGPT, or another MCP client. Each row shows the app, its access (**Read only** or **Read and write**), when it was last used, and when it was connected. Disconnecting one stops it right away.

## Keep keys safe

<Warning>Treat keys like passwords. Never commit them to source control or paste them where others can read them. If a key leaks, rotate it: create a new key, update your clients, then revoke the old one.</Warning>

---
title: "Managing websites"
description: "Add, edit, and organize the websites you monitor in Hikoo."
---

You can track multiple websites from a single Hikoo account. Each website has its own set of prompts, citations, competitors, and audit data.

## Adding a website

1. Go to the **Websites** page from the sidebar.
2. Click **Add website**.
3. Fill in the website URL, company name, target market, and description.
4. Optionally add competitors.

The new site will begin indexation and citation tracking automatically.

## Switching between websites

Use the **site switcher** in the sidebar to select the website you want to view. All dashboard pages update to show data for the selected site.

## Editing a website

Open the Websites page, select a website, and click **Edit** to update its details (URL, name, description, market).

## Deleting a website

Select a website and click **Delete**. This removes the website and all associated data (citations, prompts, audits, competitors) permanently.

<Warning>Deleting a website cannot be undone. All historical data will be lost.</Warning>

## Website limits

Your subscription plan determines how many websites you can monitor. If you reach your limit, an alert will prompt you to upgrade or remove an existing website before adding a new one.
